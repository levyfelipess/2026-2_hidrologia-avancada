## Como Executar
Com *git bash* (https://git-scm.com/install/windows):

1. Clonar o repositório:
```
git clone https://github.com/levyfelipess/2026-2_hidrologia-avancada
```

2. Acessar o diretório:
```
cd 2026-2_hidrologia-avancada
```

3. Criar ambiente virtual:
```
python -m venv .venv
```

4. Ativar ambiente virtual:
```
source .venv/Scripts/activate
```

5. Instalar o projeto completo:
```
pip install -e .
```

6. Configurar um kernel específico para o ambiente virtual:
```
python -m ipykernel install --user --name=kernel_name
```
